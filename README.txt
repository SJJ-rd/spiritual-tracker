生活轉化修持法｜完整儀軌打卡系統

使用方式：
1. 解壓縮 ZIP。
2. 直接打開 index.html 即可使用。
3. 可整包上傳到 GitHub Pages。

本版內容：
- 已放入完整《生活轉化修持法儀軌本》全文。
- 支援「儀軌導引」一步一步修持。
- 支援「完整儀軌全文」展開查看。
- 使用你提供的 bells.mp3 作為引磬聲。
- 使用你提供的 muyu.mp3 作為木魚聲。
- 開始前鳴磬三響。
- 叩首依 BPM 播放木魚。
- 每 100 叩鳴磬一次。
- 1000 叩圓滿後鳴磬三響。
- 今日打卡、十二願、習氣轉化、回向、連續天數與累積紀錄。

注意：
- 第一次播放音效需先點擊按鈕，這是瀏覽器限制。
- 紀錄儲存在本機 localStorage，換裝置或清除瀏覽資料後不會自動同步。
